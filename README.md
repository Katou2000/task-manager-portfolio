# TaskTune

日々のタスク、予定、ルーティン、目標、メモをまとめて管理できるWebアプリです。情報量や使いやすい配置は人によって異なるという前提から、画面構成を利用者自身が調整できるようにしています。

## 概要

通常タスクと軽量タスクを使い分けながら、ホーム、ボード、カレンダーで今日の行動と全体の予定を確認できます。ルーティンタスク、目標設計、自由帳では、繰り返す行動、長期目標、まだ整理できていないアイデアをそれぞれ扱います。軽量タスクは、詳細設定や長期履歴を必要としない小さなタスク向けです。自由帳は、付箋や画像を自由に配置できるスペースです。

公開デモには主要機能を把握できる少量のサンプルデータが入っています。データはブラウザ内に保存され、アカウント登録は不要です。

## 制作背景

ゲーム会社でQA業務を経験する中で、使う側で気付いた小さな使いにくさを指摘だけで終わらせず、自分で改善したいと考えて制作しました。機能数を増やすことより、利用場面に応じて迷いにくく調整できることを重視しています。

## 主な機能

- ホーム、ボード、カレンダーによるタスクと予定の確認
- 通常タスクと軽量タスクの使い分け
- ルーティンタスクと月間実績
- 目標と達成までのステップ管理
- 自由帳、メモ、ピン留め、完了履歴、テンプレート
- アプリ全体検索、Undo / Redo
- 表示項目や配置を調整できるUI設定
- JSONバックアップと復元
- PWA、オフライン利用

## UX上の工夫

- 実行予定日・開始日・期限を分け、特定日に行う予定と期間・締切を別々に扱います。
- 通常タスクはチェック後に完了を確定する2段階操作とし、誤って履歴へ移すことを防ぎます。軽量タスクは1操作で完了でき、当日の履歴はカレンダーから確認できます。
- ルーティンタスクの日付境界を午前4時にし、深夜の利用でも前日の習慣として自然に記録できます。
- カレンダーは日付の選択と追加操作を分け、閲覧中の誤操作を減らしています。
- PCでは情報を広く見渡せる配置、スマートフォンではタップ領域とドロワー操作を優先しています。

## カスタマイズ

利用者ごとに使いやすいUIが異なることを前提に、次の項目を変更できます。

- メニューの表示・非表示、順番、位置、サイズ、横幅
- 文字サイズとカード密度
- 追加ボタンの表示と位置
- 上部バーの表示項目
- Simple / Blackテーマとアクセントカラー

## 技術

- HTML
- CSS
- JavaScript
- localStorage
- Service Worker / PWA
- Git / GitHub

個人利用版ではSupabase Auth、Database、Storageを使った端末間同期も実装しています。公開ポートフォリオ版では、安全性、運用コスト、デモの分かりやすさを考慮してクラウド同期を無効化しています。

## データについて

- データは閲覧中のブラウザのlocalStorageへ保存されます。
- アカウント登録は不要で、タスクデータをクラウドへ送信しません。
- 設定画面からJSON形式でバックアップ・復元できます。
- ブラウザデータを削除すると保存内容も消えるため、継続利用時はバックアップを推奨します。

## 個人版との違い

このリポジトリは企業・採用担当者向けの公開ポートフォリオ版です。公開デモではクラウド同期を停止し、初回起動時に機能確認用のサンプルデータを生成します。既に保存データがある場合、サンプルは追加されません。

## ローカルでの起動

Service Workerを含むため、ファイルを直接開かずローカルHTTPサーバーを使用してください。

```bash
python -m http.server 8000
```

起動後、`http://localhost:8000/`を開きます。GitHub Pagesではリポジトリ配下の相対パスで動作します。
